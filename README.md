# 美剧权威评分聚合平台 (RateVibe TV Pro)

> 聚合 **IMDb**、**Rotten Tomatoes (烂番茄)**、**Metacritic**、**豆瓣电影**、**TMDb** 五大全球主流权威评分平台，一站式辨别神作、避坑烂尾，全方位展现多源深度短评与数据雷达。

---

## 🌟 核心特色与功能设计

### 1. ⚖️ 聚合天平指数 (Definitive Composite Score)
针对不同平台打分机制（IMDb 的贝叶斯加权均分、烂番茄影评人/爆米花双百分比、Metacritic 专业媒体分、豆瓣国内受众星级分布），建立归一化综合评分模型：
$$\text{综合分} = \text{IMDb} \times 35\% + \text{烂番茄折算} \times 25\% + \text{豆瓣} \times 25\% + \text{Metacritic折算} \times 15\%$$

### 2. 🎯 一目了然的四大口碑雷达筛选
- 👑 **全网封神殿 (9.0+)**：各大权威平台无一例外给出 9 分以上的零争议传世神剧（如《绝命毒师》《切尔诺贝利》《风骚律师》《继承之战》）。
- ⚠️ **断崖式烂尾预警**：美剧专属痛点功能！智能比对前几季均分与最终季均分，识别高开暴走、断崖崩盘剧集（如《权力的游戏》第八季、《西部世界》）。
- 🚫 **踩坑大避雷区 (<7.0)**：高预算/名导/强宣发但全网大翻车的避雷清单（如《偶像涡流》烂番茄 19%、《秘密入侵》单集 3.7 分），帮观众节省宝贵时间。
- ⚡ **中外审美大分歧**：直观对比欧美与华语受众的文化审美差异（如《三体 英文版》烂番茄 79% 叫好，但国内豆瓣仅 6.9 争议极大）。

### 3. 🕸️ 五维品质雷达分布 (Spider Chart)
基于纯原生 SVG 动态渲染 5 大维度：
1. **专业口碑**：Metacritic 严苛媒体分 + 烂番茄影评人新鲜度
2. **大众热度**：IMDb 与 TMDb 参评基数及全球流行度
3. **华语受众偏好**：豆瓣电影评分与五星打分比例
4. **剧情扎实度**：各季均分方差与起伏稳定性
5. **完结满意度**：最终季与季终集口碑

### 4. 📊 全季单集口碑走势矩阵 (Episode Heatmap)
细化至“单集粒度”的热力图矩阵：
- **金色 (9.8+)**：电视剧史诗级单集神回（如《绝命毒师》5x14《奥曼迪亚斯》10.0 满分神集、《继承之战》4x03《康纳的婚礼》9.9 分）。
- **绿色 (9.0 - 9.7)**：高水准单集。
- **红色 (<6.0)**：剧情崩坏暴死集（如《权力的游戏》8x06 终集 4.0 分）。

### 5. 💬 多平台精选短评与 AI 观点提炼
- **烂番茄官方 Critics Consensus**：一句话权威定调。
- **AI 智能观点萃取**：3 大推荐入坑亮点 (Pros) vs 3 大劝退雷点门槛 (Cons) + 极力推荐人群 vs 建议避开人群。
- **多源真实短评流**：支持按“豆瓣高赞短评”、“烂番茄顶级影评人 (Top Critics)”、“IMDb 深度长评”切换查阅。

### 6. ⚔️ 多剧横向对比台 (Side-by-Side Comparison)
支持将最多 3 部美剧一键拉入对比栏：
- **双色重叠雷达图**直观对比两部剧的各维度长短板。
- 多平台参数对比矩阵表。
- AI 优缺点与避雷标签并列对比。

### 7. ⏱️ 定时自动同步与更新调度控制台 (Scheduled Sync)
- **调度策略**：支持标准 5 段式 Cron 表达式（默认 `0 3 * * *` 每日凌晨 3:00 自动抓取更新）。
- **多源数据管道**：模拟 TMDb 元数据、OMDb/IMDb 权重、烂番茄爬虫、豆瓣 Rexxar 接口及 Metascore 的异步并行拉取与数据对齐。
- **健康监控与审计日志**：实时呈现 5 大数据源节点健康状态与最新更新历史。

## 🛠️ 技术架构

- **前端框架**：React 19 + TypeScript + Vite 8
- **样式美学**：Tailwind CSS (暗色流媒体现代科技设计，沉浸式高对比度品牌配色)
- **图标与动效**：Lucide React + 原生 SVG 动态渲染
- **数据结构与缓存**：以 TMDb ID 与 IMDb ID 为跨库主键关联，本地状态高效驱动，兼容接入 Python FastAPI / Redis / PostgreSQL 生产后端。
